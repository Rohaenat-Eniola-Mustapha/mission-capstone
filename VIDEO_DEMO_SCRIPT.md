# InfraTour Nigeria - Video Demo Script

**Duration:** 5-7 minutes
**Format:** Screen recording with voice-over
**Resolution:** 1920x1080 (Full HD)
**Frame Rate:** 30 fps

---

## Pre-Recording Checklist

- [ ] Clear browser cache
- [ ] Close unnecessary browser tabs
- [ ] Disable browser notifications
- [ ] Set browser zoom to 100%
- [ ] Use incognito/private window (clean state)
- [ ] Prepare sample feedback text in advance
- [ ] Test microphone levels
- [ ] Close distracting applications
- [ ] Enable "Do Not Disturb" mode
- [ ] Have water nearby for clear speaking

---

## Recording Setup

**Screen Recording Tool Options:**
- OBS Studio (free, professional)
- Loom (easy, cloud-based)
- QuickTime (Mac)
- Windows Game Bar (Windows)

**Settings:**
- Resolution: 1920x1080
- Frame rate: 30 fps
- Audio: 48kHz, 16-bit
- Bitrate: 5000 kbps (high quality)

- Use Chrome or Firefox for best compatibility
- Enable cursor highlight extension for visibility

## Tips for Recording

1. **Speak slowly and clearly** - Viewers may be non-native English speakers
2. **Pause between sections** - Easier to edit
3. **Use descriptive language** - "Click the emerald green button" vs "click this"
4. **Avoid filler words** - "um," "uh," "like"
5. **Show, don't tell** - Let interactions speak for themselves
6. **Practice first** - Do a dry run without recording
7. **Stay hydrated** - Keep water nearby for clear voice
8. **Smile while speaking** - It comes through in your voice tone

---

## Accessibility Considerations

- **Add captions** - Use YouTube auto-captions or manual transcription
- **Describe visual elements** - Mention colors, positions, icons
- **Provide transcript** - Include full script as text file
- **Use clear language** - Avoid jargon or explain technical terms
